# PY/01 — Pandas Assignment: Air Quality Dataset

A guided notebook covering core pandas skills using the `airquality` dataset from `pydataset`.

## Contents

- **Task 1** — Inspecting structure (shape, dtypes, head/tail, info)
- **Task 2** — Basic summary stats (describe, nunique)
- **Task 3** — Missing values (counting, median/mean imputation)
- **Task 4** — Selecting columns & rows (lists, iloc, boolean masks, isin)
- **Task 5** — Filtering & conditions (combined booleans, between)
- **Task 6** — Sorting (multi-column sort)
- **Task 7** — Duplicates (detecting, creating, removing)
- **Task 8** — Derived columns (Fahrenheit→Celsius, boolean flags, pd.cut)
- **Task 9** — Groupby & aggregation (agg, boolean-to-int counting)
- **Task 10 (optional)** — Quick sanity plots (histogram, line plot)
